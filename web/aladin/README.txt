Aladin Lite 3.8.2

aladin-3.8.2.js is Aladin Lite, the sky viewer in Cosmos Collection's FOV Simulator,
by the Centre de Données astronomiques de Strasbourg (CDS, Université de Strasbourg / CNRS).
It is included unmodified, as published at:
  https://aladin.cds.unistra.fr/AladinLite/api/v3/3.8.2/aladin.js

Source code: https://github.com/cds-astro/aladin-lite

Aladin Lite is free software under the GNU Lesser General Public License, version 3
(COPYING.LESSER.txt), which builds on the GNU General Public License, version 3
(COPYING.txt). You may replace this file with another build of Aladin Lite 3; if it
is missing, Cosmos Collection loads Aladin Lite from the address above instead.
