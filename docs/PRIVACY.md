# Privacy Policy

Cosmos Collection has no accounts, analytics or telemetry. Your catalog, images, sessions and settings stay on your computer. Nothing is sent to the Cosmos Collection project.

Some features need online data, so the app contacts these services:

| Service | What for | What it receives |
|---|---|---|
| GitHub | Checking for and downloading updates | A request for the latest release |
| CDS Strasbourg (SIMBAD, VizieR, Aladin), with Harvard and ESA Sky as backups | Object details, sky images in the FOV Simulator, star catalogs for plate solving | Object names and sky coordinates |
| Your weather provider (Open-Meteo, OpenWeatherMap, Visual Crossing or WeatherAPI) | Weather forecasts | Your observing location's coordinates, and your API key if the provider needs one |
| OpenStreetMap | Finding your location on the map in Settings | The place you search for or the point you pick, and the map area shown |
| unpkg.com, jsDelivr | The map's code | A request for the map's code |
| astrometry.net, only if you choose it for plate solving | Plate solving | The image being solved, and your API key |

Like any website you visit, each service also sees your IP address. Each has its own privacy policy.

The update check runs on its own when the app starts. Everything else runs when you use a feature that needs it.

## Turning It Off

- **Settings > Application Settings > Check for updates on startup**: turn this off to stop the automatic update check.
- **Settings > Application Settings > Offline mode**: while it's on, the app doesn't go online at all. Links that open your web browser and NINA (on your local network) still work.
